# گربه‌های سایت

سه گربه (مشکی، نارنجی، سفید) کل صفحه را قلمرو خودشان می‌دانند. طراحی‌شان ۱۲ ژست دست‌کشیده برای هر گربه است. حرکت (راه رفتن، پرش، نفس کشیدن، لرزیدن) با کد روی همین ژست‌ها ساخته می‌شود.

## کارهایی که می‌کنند

| رفتار | کِی |
|---|---|
| دنبال کردن نقطه لیزر | موس حرکت کند (روی موبایل: تپ). گربه مشکی عاشقش است: می‌دود، کمین می‌کند، باسن تکان می‌دهد و می‌پرد |
| نشستن روی لبه بخش‌ها | با اسکرول همراه قفسه جابه‌جا می‌شوند و وقتی قفسه از صفحه بیرون رفت، می‌پرند پایین |
| هل دادن مهارت‌ها از روی میز | گاهی (بیشتر گربه سفید) روی یک مهارت می‌نشیند، به شما زل می‌زند و با پنجه می‌اندازدش. بعد برمی‌گردد سر جایش |
| رفتن توی جعبه | کارت تماس یک جعبه مقوایی است. گربه نارنجی عاشقش است و از آن سرک می‌کشد |
| خوابیدن در آفتاب | یک لکه آفتاب آرام کف صفحه حرکت می‌کند. گربه نارنجی دنبالش می‌رود و می‌خوابد |
| راه رفتن روی متن | گربه روی متن تایپ‌شده هیرو راه می‌رود و «fjjjkf» تایپ می‌کند. بعد پاک می‌شود |
| نوازش | موس را روی گربه تکان بدهید: خرخر و قلب. زیاد ادامه بدهید، یک پنجه می‌خورید |
| کلیک روی گربه | ذوق‌زده می‌پرد و ستاره پخش می‌کند |
| اسکرول سریع | جا می‌خورند، پشتشان قوز می‌کند و می‌لرزند |
| زومیز | گاهی یک گربه دیوانه‌وار کف صفحه می‌دود |
| بی‌کاری ۲۰ ثانیه | یکی‌یکی گلوله می‌شوند و چرت می‌زنند (Zzz). با اولین حرکت بیدار می‌شوند و کش می‌آیند |
| لیسیدن پنجه، کش آمدن، غلت زدن، نفس کشیدن | خودبه‌خود |

دکمه پنجه 🐾 در نوار بالا گربه‌ها را خاموش/روشن می‌کند. با تنظیم «کاهش حرکت» سیستم‌عامل، گربه‌ها فقط می‌نشینند و می‌خوابند.

## ژست‌ها

| ژست (نام فایل) | کجا استفاده می‌شود |
|---|---|
| `sit` | نشستن، زل زدن، سرک کشیدن از جعبه، خرخر |
| `walk` | راه رفتن، روی متن راه رفتن |
| `run` | دنبال لیزر دویدن، زومیز، پرش افقی |
| `crouch` | کمین، لحظه پریدن و فرود |
| `stretch` | کش آمدن |
| `hopAway` | پریدن به جای بالاتر |
| `pounceUp` | شکار لیزر، ذوق بعد از کلیک |
| `reach` | پنجه زدن، انداختن اشیا |
| `groom` | لیسیدن پنجه |
| `sleep` | خواب (و خواب در آفتاب) |
| `startled` | ترسیدن از اسکرول سریع |
| `roll` | غلت زدن روی کمر بعد از نوازش |

### عوض کردن یا بهتر کردن ژست‌ها
- **راه ساده:** یک عکس PNG/WebP با پس‌زمینه شفاف بسازید و به جای `public/cats/<black|white|orange>/<ژست>.webp` بگذارید. گربه باید رو به **راست** باشد.
- **راه خودکار:** برگه‌های ژست را (شبکه ۳ ستون × ۴ ردیف: مشکی، سفید، نارنجی) در `art/` بگذارید و این را اجرا کنید:
  ```bash
  pip install pillow numpy scipy
  python3 scripts/cut-poses.py
  ```
  اسکریپت هر ژست را جدا می‌کند، پس‌زمینه را شفاف می‌کند، نقطه زیر پا را پیدا می‌کند و `src/cats/poses.json` را می‌سازد.
- **ژست جدید** (مثلاً خمیازه): اسمش را به `ORDER` در `src/cats/PoseCat.jsx` و به تابع `pickImage` در `src/cats/brain.js` اضافه کنید.

## تغییر دادن

همه چیز در `src/cats/cats.config.js` است:
- **`weights`:** شخصیت هر گربه. عدد بزرگ‌تر یعنی آن رفتار را بیشتر انجام می‌دهد. مثلاً `knock: 0` یعنی هیچ‌وقت چیزی را نمی‌اندازد.
- **`size`:** اندازه در دسکتاپ و موبایل.
- **`sleepAfterMs`:** بعد از چند میلی‌ثانیه بی‌کاری بخوابند.
- **`speed`:** سرعت راه رفتن، یورتمه، دویدن و زومیز.

هر عنصری در صفحه که `data-cat-surface` داشته باشد، جایی است که گربه‌ها می‌توانند رویش بنشینند. مقدارها:
- `shelf` (قفسه)
- `chip` (قابل انداختن)
- `box` (جعبه)
- `keyboard` (متن تایپی)
- `pills` (دکمه‌ها)

| `src/cats/props.js` | انداختن اشیا، ذرات (Zzz، ستاره، قلب) |
| `src/index.css` | لیزر، آفتاب، ذرات و استایل گربه‌ها، زیر بخش «Cats» |
