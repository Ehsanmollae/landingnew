# راهنمای ساخت ویدیوی گربه‌ها

سایت دیگر گربه‌ها را «پخش» نمی‌کند؛ ویدیو را با موقعیت موس **جلو و عقب می‌برد** (scrub).
موس سمت چپ صفحه = اولین فریم ویدیو، موس سمت راست = آخرین فریم.
پس اگر در ویدیو گربه‌ها نگاهشان را آرام از چپ به راست بچرخانند، در سایت به نظر می‌رسد دنبال موس نگاه می‌کنند.

تا وقتی فایل‌ها را اضافه نکرده‌اید، گربه‌های SVG موقت نمایش داده می‌شوند. به محض اضافه شدن `public/cats/look.mp4` ویدیو خودکار جایگزین می‌شود.

---

## ۱. ویدیوی اصلی نگاه — `look.mp4` (ضروری)

| ویژگی | مقدار |
|---|---|
| مدت | ۴ تا ۶ ثانیه |
| فریم‌ریت | ۲۴ یا ۳۰ (یعنی ۱۲۰ تا ۱۸۰ فریم) |
| ابعاد | 1920×1080 (افقی) |
| صدا | ندارد |

**قوانین مهم:**
1. **دوربین کاملاً ثابت.** هیچ زوم، حرکت یا لرزشی نباشد.
2. **فریم اول:** هر سه گربه به **منتهی‌الیه چپ** کادر نگاه می‌کنند (سر و چشم هر دو).
   **فریم آخر:** هر سه به **منتهی‌الیه راست** نگاه می‌کنند.
   **فریم وسط:** مستقیم به دوربین (به بیننده) نگاه می‌کنند.
3. چرخش با **سرعت ثابت** باشد (بدون شتاب و توقف)، تا نگاه با موس هماهنگ بماند.
4. **هیچ چیز دیگری زیاد حرکت نکند.** هر حرکتی (دم، پلک، ذرات نور) هم با موس جلو/عقب می‌رود و عجیب می‌شود. حرکات خیلی ریز اشکالی ندارد.
5. **ترکیب‌بندی:** گربه‌ها در **نیمه راست** کادر باشند؛ ۴۵٪ سمت چپ برای متن خالی و کمی تیره‌تر باشد.
   (در نسخه فارسی سایت، ویدیو خودکار آینه می‌شود تا گربه‌ها سمت چپ و متن سمت راست باشد. پس فقط یک نسخه بسازید.)
6. سه گربه با ظاهر متفاوت، در یک فضای فانتزی (مثلاً شب مهتابی، تپه بنفش، ستاره‌ها، کلاه جادوگری روی یکی).

## ۲. کلیپ‌های واکنش (اختیاری)

هر کلیپ ۱ تا ۲ ثانیه است و **یک بار کامل پخش می‌شود** (نه اسکراب).
**قانون طلایی:** فریم اول و آخر هر کلیپ واکنش باید **دقیقاً همان فریم وسط `look.mp4`** باشد (گربه‌ها رو به دوربین)، تا جابه‌جایی بین ویدیوها دیده نشود.

| فایل | کی پخش می‌شود | پیشنهاد حرکت |
|---|---|---|
| `react-click.mp4` | کلیک روی هر جای صفحه | همه با هم یک پرش کوچک |
| `react-scroll.mp4` | اسکرول سریع | گوش‌ها عقب، چشم‌ها گرد، کمی جا خوردن |
| `react-about.mp4` | رسیدن به بخش «درباره من» | یکی دست تکان می‌دهد |
| `react-skills.mp4` | بخش «مهارت‌ها» | سر تکان دادن |
| `react-projects.mp4` | بخش «نمونه‌کارها» | یکی دور خودش می‌چرخد |
| `react-experience.mp4` | بخش «سوابق» | سر تکان دادن |
| `react-contact.mp4` | بخش «تماس» | پرش خوشحال + قلب |

هر کلیپی که نسازید، آن واکنش در حالت ویدیو اجرا نمی‌شود. خطایی هم پیش نمی‌آید.

## ۳. روش ساخت

### روش الف: هوش مصنوعی (سریع‌تر)
با ابزارهای image-to-video که «فریم اول و آخر» می‌گیرند (مثل Higgsfield، Kling، Runway، Luma):
1. یک تصویر پایه بسازید: سه گربه، فضای فانتزی، گربه‌ها رو به دوربین. **این فریم وسط است؛ ذخیره‌اش کنید.**
2. با ویرایش همان تصویر (inpaint یا edit) دو نسخه بسازید: یکی با نگاه همه به چپ، یکی به راست. پس‌زمینه دقیقاً ثابت بماند.
3. ویدیو ۱: فریم اول «نگاه چپ»، فریم آخر «رو به دوربین». ویدیو ۲: فریم اول «رو به دوربین»، فریم آخر «نگاه راست».
   در پرامپت بنویسید: `static camera, only the cats' heads turn slowly, no other motion`.
4. دو ویدیو را پشت هم بچسبانید (مرحله ۴ پایین).
5. برای کلیپ‌های واکنش: فریم اول **و** آخر = همان تصویر «رو به دوربین».

### روش ب: Blender (کنترل کامل، فریم‌به‌فریم)
1. گربه‌ها را مدل کنید (یا از Sketchfab یا Mixamo بگیرید) و برای هر کدام استخوان `Head` داشته باشید.
2. دوربین را ثابت کنید.
3. فریم ۱: چرخش Y سر = +۴۰ درجه (نگاه به چپ کادر). فریم ۱۲۰: −۴۰ درجه. Interpolation را **Linear** کنید.
4. چشم‌ها را با یک Empty که از چپ به راست حرکت می‌کند و قید Track To/Damped Track کنترل کنید.
5. Render به صورت PNG Sequence (`frame_0001.png` …).
6. برای واکنش‌ها از فریم ۶۰ (وسط) شروع کنید و به همان ژست برگردید.

## ۴. خروجی گرفتن (خیلی مهم برای روان بودن)

ویدیوی معمولی هر چند ثانیه یک keyframe دارد و جلو/عقب بردنش **پرش‌دار** است.
باید **همه فریم‌ها keyframe** باشند (`-g 1`):

```bash
# ویدیوی اصلی دسکتاپ
ffmpeg -i input.mp4 -an -c:v libx264 -g 1 -crf 22 -pix_fmt yuv420p -movflags +faststart -vf scale=1920:-2 look.mp4

# نسخه سبک موبایل
ffmpeg -i input.mp4 -an -c:v libx264 -g 1 -crf 26 -pix_fmt yuv420p -movflags +faststart -vf scale=1280:-2 look-mobile.mp4

# اگر PNG Sequence دارید (Blender)
ffmpeg -framerate 30 -i frame_%04d.png -an -c:v libx264 -g 1 -crf 22 -pix_fmt yuv420p -movflags +faststart look.mp4

# چسباندن دو نیمه (روش هوش مصنوعی)
printf "file 'left-to-center.mp4'\nfile 'center-to-right.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -an -c:v libx264 -g 1 -crf 22 -pix_fmt yuv420p -movflags +faststart look.mp4

# کلیپ‌های واکنش (یک بار پخش می‌شوند؛ keyframe معمولی کافی است)
ffmpeg -i click.mp4 -an -c:v libx264 -crf 24 -pix_fmt yuv420p -movflags +faststart react-click.mp4
```

حجم هدف: `look.mp4` زیر ۸ مگابایت، `look-mobile.mp4` زیر ۴ مگابایت، هر کلیپ واکنش زیر ۱.۵ مگابایت.
